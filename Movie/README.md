# Movie Poster Downloader - بهبود شده

سه اسکریپت برای دانلود، سازمان‌دهی و مدیریت پوسترهای فیلم

## فایل‌ها

### 1. `download_posters.py` - دانلود کننده اصلی (بهبود شده)

**بهبودیها:**
- ✅ **عدم دانلود مجدد** - قبل از دانلود، فایل را چک می‌کند
- ✅ **ردیابی وضعیت** - تعداد فایل‌های جدید و رد شده را نمایش می‌دهد
- ✅ **خطاهای کمتر** - اگر دانلود شکست بخورد، فایل ناقص پاک می‌شود

**استفاده:**

```bash
# دانلود از صفحه 184
python download_posters.py --start-page 184

# ادامه دانلود و اضافه کردن به موجود
python download_posters.py --start-page 199 --append

# دانلود محدوده مشخص
python download_posters.py --start-page 200 --end-page 210 --append
```

### 2. `organize_by_year.py` - سازمان‌دهی و حذف تکراری

**ویژگی‌ها:**
- 🗂️ **سازمان‌دهی بر حسب سال** - تمام فایل‌ها در پوشه‌های سال منتقل می‌شوند
- 🔍 **تشخیص تکراری** - از طریق مقایسه محتوای فایل (MD5 hash)
- 🗑️ **حذف خودکار** - فایل‌های تکراری حذف می‌شوند

**استفاده:**

```bash
# سازمان‌دهی و حذف تکراری
python organize_by_year.py
```

**نتیجه:**
```
posters/
├── 2020/
│   ├── 184_001_دانلود_فیلم_Poor_Things_2023.jpg
│   └── ...
├── 2021/
│   ├── 184_002_دانلود_فیلم_War_Pony_2022.jpg
│   └── ...
└── ...
```

### 3. `cleanup_duplicates.py` - فقط حذف تکراری (اختیاری)

اگر فقط می‌خواهید فایل‌های تکراری را حذف کنید بدون سازمان‌دهی:

```bash
python cleanup_duplicates.py
```

## جریان کار توصیه شده

### برای اولین بار:
```bash
# 1. دانلود پوسترها
python download_posters.py --start-page 184 --end-page 407

# 2. سازمان‌دهی و حذف تکراری
python organize_by_year.py
```

### برای ادامه دانلود:
```bash
# 1. ادامه دانلود
python download_posters.py --start-page 408 --append

# 2. مجدد سازمان‌دهی کنید
python organize_by_year.py
```

## نکات مهم

1. **بدون دانلود مجدد**: اگر فایل موجود باشد، دانلود نمی‌شود
2. **حذف خودکار تکراری**: اگر دو فایل یکی باشند، یکی حفظ می‌شود (جدیدتر)
3. **استخراج سال**: سال از نام فایل یا اطلاعات فیلم استخراج می‌شود
4. **ایمن**: قبل از حذف، هش‌ها مقایسه می‌شوند

## سوال‌های متداول

**Q: چطور می‌دانم فایل تکراری است؟**
A: سیستم محتوای هر فایل را با هش MD5 مقایسه می‌کند. اگر دو فایل یکسان باشند، یکی حذف می‌شود.

**Q: اگر دانلود قطع شود چه می‌شود؟**
A: فایل‌های ناقص خودکار پاک می‌شوند و دفعه بعد دوباره دانلود می‌شوند.

**Q: آیا فایل‌های قدیمی محفوظ می‌مانند؟**
A: بله! هر فایل به سال مربوط به خود منتقل می‌شود.
