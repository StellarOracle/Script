# 🎬 Digimoviez Poster Downloader & Organizer

یک ابزار خودکار و هوشمند به زبان پایتون برای استخراج، دانلود، حذف فایل‌های تکراری و دسته‌بندی پوسترهای فیلم از وب‌سایت دیجی‌موویز بر اساس سال ساخت.

---

## ✨ ویژگی‌های کلیدی

* **استخراج پیشرفته لینک‌ها:** پیدا کردن بالاترین کیفیت پوسترها با پردازش ویژگی `srcset` در تگ‌های تصاویر.
* **دانلود پایدار و امن:** مجهز به سیستم مدیریت خطا، بازشمارش دانلود (Retry Backoff) و حذف خودکار فایل‌های ناقص در صورت بروز خطا.
* **کنترل پروکسی:** غیرفعال‌سازی خودکار پروکسی‌های سیستم برای جلوگیری از اختلال در شبکه ایران.
* **پاک‌سازی فایل‌های تکراری:** شناسایی و حذف تصاویر تکراری بر اساس مکانیسم هش محتوایی (MD5 Hash).
* **دسته‌بندی هوشمند:** استخراج سال ساخت فیلم از نام فایل یا عنوان متادیتا و انتقال خودکار تصاویر به پوشه‌های مجزا براساس سال (مثلاً `posters/2023/`).

---

## 🛠️ پیش‌نیازها و نصب

برای اجرای این اسکریپت‌ها به پایتون نسخه 3.6 یا بالاتر نیاز دارید.

ابتدا وابستگی‌های پروژه را با دستور زیر نصب کنید:
```bash
pip install requests beautifulsoup4
۱. اجرای همه‌کاره (پیشنهادی)
راحت‌ترین راه، اجرای فایل مدیریت مرکزی run_all.py است:

حالت تعاملی (Interactive): دستور زیر را بزنید تا یک منوی ساده در ترمینال باز شود و کار خود را انتخاب کنید
python run_all.py
دانلود و دسته‌بندی مستقیم پشت سر هم:
python run_all.py --both --start-page 184
۲. اجرای مجزای اسکریپت‌ها (حرفه‌ای)
اگر تمایل دارید مراحل را به صورت دستی مدیریت کنید، دستورات زیر در دسترس هستند:

فقط استخراج لینک‌ها:
python extract_poster_urls.py --start 1 --end 100
فقط دانلود پوسترها (با امکان رزومه و ادامه):
python download_posters.py --start-page 184 --end-page 200 --append
فقط حذف تکراری‌ها و دسته‌بندی بر اساس سال:
python organize_by_year.py

💡 نکات مهم
🔒 عدم نیاز به VPN: در اسکریپت‌ها تنظیماتی قرار داده شده (os.environ['no_proxy'] = '*') تا پروکسی‌های سیستم به‌طور موقت دور زده شوند. اگر وب‌سایت مقصد فیلتر باشد یا نیاز به پروکسی خاصی داشته باشید، ممکن است نیاز به شخصی‌سازی این بخش در فایل download_posters.py داشته باشید.
